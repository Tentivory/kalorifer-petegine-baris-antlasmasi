# Kalorifer Peteğine Barış Antlaşması

> Kışın 03:17'de cıtırdayan bir metal parçasıyla diplomatik ilişki kurmanın
> ulusal protokolü. Peteğe dokunulmaz. Çaya dokunulur.

Bu yazılım, gece yarısı evdeki kalorifer peteğinin çıkardığı sesleri
**savaş suçu** değil, **teknik ısınma** olarak tescil eder ve taraflar
arasında resmi ateşkes metni basar.

Anlam aramayın. Antlaşma yeter.

## Neden var?

Çünkü:

1. Peteğe bağırmak diplomatik kriz çıkarır.
2. Vana kapatmak Cenevre ihlalidir (bu repoda).
3. Çay demlemek her protokolün 8. maddesidir, yazılmasa bile.

## Kurulum

```bash
git clone https://github.com/Tentivory/kalorifer-petegine-baris-antlasmasi.git
cd kalorifer-petegine-baris-antlasmasi
python3 antlasma.py
```

Parametreyle (daha resmi):

```bash
python3 antlasma.py --citirt 23 --kat 4
```

## Çıktı neye benzer?

Resmi suret. Taraflar, maddeler, tazminat (birim: sıcak su),
temsilci unvanı ve en altta bir damga.

Dördüncü kısım "gizli ek"tir. Orada bir cümle vardır.
Parti afişi değildir. Isınmayan şeyin yalnızca peteğe ait olmadığına dair
ufak bir hatırlatmadır. Görmezden gelebilirsiniz; peteğe de öyle yapıyoruz.

## Lisans

Peteğin keyfine kalmıştır. Kod açıktır, cıtırtı teliflidir.
